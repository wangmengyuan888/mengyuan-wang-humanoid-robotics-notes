## 阅读方式

按编号顺序阅读；已有基础时可直接进入对应专题。正文中的来源页码、代码路径、版本条件及缺失说明用于核对知识与复现条件。

先读 00 和 01，再依次学习控制、建图导航、视觉与语言；对照作业参考笔记查看实际操作。课程作业没有现成解答的地方保留题目和限制，不虚构结果。
