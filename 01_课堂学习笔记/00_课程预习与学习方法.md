# 课程预习与学习方法

作者：**Mengyuan Wang**。这是我在上课及实验过程中整理的学习笔记，用于复习与交流分享。

## 1. 学习主线

先理解机器人由机体、传感器、计算与驱动组成，再学 ROS 消息、坐标系和仿真；随后训练行走策略，完成建图定位、路径规划与自主探索；最后将视觉、语音和任务决策接入运动系统。

学习目标不是记住命令，而是能说明数据从哪里来、属于哪个坐标系、怎样进入控制器、失败时如何停止。每章记录输入、输出、参数、依赖、运行顺序、结果与未解决问题。代码中的模型配置与论文公式需要相互对照。

## 2. 预备能力

Python 用于训练、数据处理与 ROS 节点；C++ 用于控制、驱动与高效计算。Linux 需要掌握工作目录、权限、环境变量、进程、网络和构建工具。数学重点为向量与矩阵、旋转和刚体变换、概率协方差、导数及优化。

控制基础包括位置/速度/力矩的区别、PD 反馈、采样周期和饱和。强化学习基础包括状态、动作、奖励、策略与价值；视觉基础包括像素、相机内参、深度、标定与投影。

## 3. ROS 的作用与课程版本

ROS 是机器人软件库和工具生态，不是取代 Linux 的操作系统内核。它为感知、规划、控制等模块提供通信接口、软件包、配置、调试和记录工具。节点承担功能，话题传消息，服务处理请求，动作组织长任务，TF 管理坐标变换。

本课程复现环境为 Ubuntu 20.04、ROS 1 Noetic、ROS 2 Foxy。个人实验主要含 ROS 1 Gazebo 与 ROS 1/ROS 2 桥接；X2 示例与部分环境教程使用 Humble，具体版本见各篇说明。不能在同一终端随意叠加各发行版。

课程原材料对虚拟机、WSL、显卡和驱动的限制是历史支持范围，不是 ROS 的普遍限制。RTX 50 系列无法配置等绝对说法不作为当前结论。用户 Docker 方案作为独立实践保留，成功与否取决于 GPU、显示、设备访问和软件组合。详细 ROS 2 概念与操作见 [X2 第一节](../03_灵犀X2二次开发/01_具身智能导论与ROS2通信.md) 和 [第二节](../03_灵犀X2二次开发/02_ROS2工作空间与移动机器人实战.md)。

## 4. 怎样安排每章实验

先运行课程基线，确认环境与预训练模型；再读关键调用链；每次改少量参数，记录差异、模型与日志编号；最后按一致评估条件比较。把程序启动成功、流程跑通和性能验证分开记录。

课程作业强调自行理解与实现，不把调库当全部工作。开班材料建议每周预留较多实践时间，提交第一版后根据讲解迭代。课件包含课程平台登录、PC 提交作业、讨论区提问、截止与结业规则；这些属于原课程教学安排，仓库不把历史截止日期或权益当作当前承诺。

开班 PDF 的安排页写第五期，而源目录名为第六期，部分课件日期为 2025。仓库沿用用户提供目录作为材料来源，不擅自改写 PDF 的实际期次和时间。文件中的期次和日期按原记录注明，不据目录名推断授课日期。

课程的 YOLO、SLAM 和自主探索推荐中有企业常用、排名最好等未给统计口径的表述，正文不将其作为事实。材料提供的在线 Feishu 文档和视频，仅在本地内容已实际提供时纳入知识提取；未能访问的外链只保留为推荐入口，不能宣称已阅读全文。
