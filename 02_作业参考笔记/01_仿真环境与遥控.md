按这个流程跑。

在宿主机（不是容器内）的终端执行：

```Bash
xhost +local:root
```

1. **进入 Docker**

```Plain Text
docker start ros1_noetic
docker exec -it ros1_noetic bash
```

2. **进入工程并 source**

```Plain Text
cd /root/ros1_ws/robocup_g1
source devel/setup.bash
```

3. **启动 Gazebo 仿真**

新开一个 Docker 终端，执行：

```Plain Text
cd /root/ros1_ws/robocup_g1
source devel/setup.bash
export LIBGL_ALWAYS_SOFTWARE=1
roslaunch unitree_guide gazebo.launch
```

默认是键盘控制。如果想一开始就用手柄：

```Bash
roslaunch unitree_guide gazebo.launch control_input_mode:=gamepad
```

4. **启动控制器 junior_ctrl**

再开一个 Docker 终端：

```Plain Text
docker exec -it ros1_noetic bash
cd /root/ros1_ws/robocup_g1
source devel/setup.bash
rosrun unitree_guide junior_ctrl
```

5. **使用方式**

键盘模式下：

```Plain Text
2：PASSIVE -> fixed stand
4：fixed stand -> LOCOMOTION
1：回 PASSIVE
W/S：前后
A/D：左右
J/L：左转/右转
空格：速度归零
5：切换键盘/手柄模式
```

手柄模式下：

```Plain Text
A：PASSIVE -> fixed stand
Start：fixed stand -> LOCOMOTION
B：回 PASSIVE
左摇杆：前后、左右移动
右摇杆横轴：转向
```

运行中也可以切换模式：

```Plain Text
rosparam set /control_input_mode keyboard
rosparam set /control_input_mode gamepad
```

建议流程是：先启动 Gazebo，按播放键；然后运行 `junior_ctrl`；输入 `2` 站起来；Gazebo 里 Reset Model Poses；再输入 `4` 进入行走模式。
