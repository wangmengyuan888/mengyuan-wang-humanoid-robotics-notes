## 重点概念

### SLAM：同步定位与建图

课程开源的SLAM可以用的源码：

https://github.com/Nova-Valley/agibot-x2-navigation

SLAM（Simultaneous Localization and Mapping，同步定位与建图）。

### 多传感器融合 SLAM

**核心原理**

紧耦合或松耦合地融合多种传感器的数据，最常见的是激光惯性里程计（LiDAR Inertial Odometry，LIO）和视觉惯性里程计（Visual Inertial Odometry，VIO）。

它利用IMU的高频数据来预测运动、补偿畸变，并结合激光或视觉的观测进行联合优化，以得到更精确、鲁棒的位姿估计。

**主要特色**

优点：鲁棒性极高，能够取长补短。IMU可以弥补激光/视觉在快速运动或特征缺失时的不足，而激光/视觉可以校正IMU的累积漂移，非常适合高动态、复杂的场景。

缺点：系统更复杂，对传感器之间的时间同步和外参标定要求极高，计算资源消耗也更大。

### SLAM 的处理流程

1. 感知（Sensing）：获取环境与自身运动的多传感器观测。
2. 定位（Localization）：实时解算机器人6自由度空间位姿。图中包括 Roll、Pitch、Yaw。
3. 建图（Mapping）：构建2D导航图与3D环境结构模型。
4. 优化（Optimization）：通过闭环检测与全局优化消除漂移，保证系统一致性。

## 理解与勘误

### SLAM 与航位推算

根据编码器或惯性积分预测运动会积累误差；SLAM 在未知环境中同时估计位姿与地图，利用重复观测形成约束。激光侧重几何，视觉提供纹理，多传感器融合组合不同优势。

激光在长走廊或空旷区可能退化，视觉在弱纹理、模糊和光照变化下可能失效。IMU 提供高频运动信息，但会漂移。融合依赖时间与空间标定，不能只接上两个话题就保证鲁棒。

闭环检测与全局优化属于某些完整 SLAM 系统的组成；FAST-LIO 类里程计本身不一定提供全局回环。课件流程图出现消除漂移，是目标说明，不能解读为所有漂移必然消除。

### 外参、坐标修正与时间

LiDAR 与 IMU 之间是刚体变换。标定求取变换，rectifier 按给定参数变换数据，两者不同。启动修正节点不证明外参被自动估计，也不能消除全部时间偏差。

课程先运行 `py_examples pcl_rectifier` 与 `imu_rectifier`，再启动建图。需要检查输出话题、frame、方向、单位、时间和下游配置。不要在 rectifier 与算法外参中重复施加同一旋转。

课件用恒等 `map → odom` 静态 TF 连接简化图。若定位/SLAM 已动态发布同一变换，再加静态发布会冲突。map 与 odom 不总是重合，实际应确定唯一发布者和坐标定义。

### 启动建图与保存

课件入口为：

```bash
ros2 launch spark_fast_lio mapping_agibot.launch.yaml
```

这是课程工程包名，依赖已正确构建和 source。在线检查传感频率、配准残差、轨迹与地图重合，低速遍历具有足够几何结构的场景，避免只看日志多就判断正常。

`robosense-e1r.yaml` 中示例：

```yaml
pcd_save:
  pcd_save_en: true
  interval: 300
```

课件 interval 单位是帧数，不是秒。实际保存的是增量点还是局部/累计地图需查看实现，不能只凭描述认定文件之间不会重复。

### 点云分块、合并与降采样

分块保存便于保留已采集数据和控制文件规模，但有分块文件不等于程序能从断点自动恢复状态估计。合并前检查所有块是否位于共同坐标；若不一致还需配准，直接拼接不会自动修复漂移。

课程 `merge_PCD.py` 遍历 scan 文件，输出 `map_merge.pcd`，示例 voxel_size=0.1 m。体素内以代表点替代原点集，值大则更稀疏，值小则保留更多细节。课件推荐区间只是室内示例，细柱或门框需检查是否丢失。

原文 `spark_fast_lio` 与 `spark-fast-lio` 文件路径互相交换，不宜照抄 `cd`。应先定位实际 `PCD` 目录和脚本，再执行，保留原地图副本。合并地图不自动成为全局一致、无误差地图。

### 已有地图定位

加载保存地图，启动 `lidar_localization_ros2 lidar_localization.launch.py`，在 RViz 用 `2D Pose Estimate` 给初值，检查当前点云与地图对齐。课件把这一过程也叫校准，它实际是定位初始化，与传感器外参标定不同。

地图匹配通常只在一定初值范围内收敛。初始化后要测试位姿连续性、重定位、动态物体影响和定位超时。地图 frame、驱动处理与建图时保持一致。

### SLAM 与里程计的区别

LIO/VIO 首先提供里程计估计，不意味着系统一定包含闭环检测和全局优化；具备相应建图和优化模块后才构成更完整的 SLAM 系统。闭环与全局优化用于约束漂移，不能保证把漂移完全消除。激光雷达也可能受强光、玻璃、反射率和天气影响。

视觉 SLAM 可以通过特征匹配或光度误差估计运动，再利用多视几何恢复结构。单目纯几何估计通常存在尺度不确定性；加入 IMU、已知尺寸或其他观测后可以提供尺度约束。
