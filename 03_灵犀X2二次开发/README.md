## 阅读方式

按编号顺序阅读；已有基础时可直接进入对应专题。每节先讲重点概念，再给出理解与勘误，最后保留原有文字、代码和操作记录。概念说明中的原有简化或错误单独解释，不把补充代码当作原记录，也不推测补写照片中被遮挡的内容。

初学 ROS 2 先读 01–02；设备二次开发再读 03–06，最后学习策略、交互及导航。涉及具体固件和 SDK 的字段以实际接口为准，本仓库没有连接真机复测。
